# Warehouse AGV Pathfinding - BFS vs DFS

## Overview
This project simulates an Automated Guided Vehicle (AGV) navigating a warehouse floor using **Breadth-First Search (BFS)** and **Depth-First Search (DFS)**. Built for an AI Fundamentals lab, it compares path optimality, memory usage, and exploration strategies.

## Features
- **Customizable grid** (fixed 3×3, 10×10, random generation, or trap maze)
- **ASCII visualization** with X/Y axes and color-coded cells
- **Performance comparison** (path length & nodes visited)
- **Dynamic analysis** – automatically explains whether DFS got lucky or failed
- **100% pure Python** – no external libraries required
